# Nice View Residence

Лендинг жилого комплекса на чистом HTML, CSS и JavaScript. Без сборщиков, без фреймворков, без зависимостей в рантайме.

## Структура

```
niceview-vanilla/
├── index.html        разметка: header / main / footer, секции по id
├── css/
│   └── bundle.css     единый файл стилей — один HTTP-запрос
├── js/
│   └── app.js          вся интерактивность одним файлом
├── img/                 изображения: webp как основной формат, jpg — фолбэк
├── favicon.svg
└── package.json
```

## Разделы страницы

- **Hero** — полноэкранный фон, CTA-кнопка
- **Philosophy** — статистика компании, инлайн-иконки, tilt-эффект на карточках
- **Apartments** — каталог квартир, рендерится из массива данных в `app.js`
- **Infrastructure** — расстояния до ключевых точек рядом с комплексом
- **Gallery** — слайдер с точками-пагинатором
- **Contacts** — форма заявки, модалка запроса каталога

Мобильное меню собрано без JavaScript — на чекбоксе и `:checked`-селекторах в CSS.

## Производительность

Изображения отдаются через `<picture>` и `srcset` с несколькими вариантами ширины — браузер сам выбирает подходящий под экран и плотность пикселей. Крупные фоновые фото сжаты под реальный размер показа. Мелкие иконки инлайнены прямо в разметку — без лишних запросов. Шрифты Google Fonts подключены асинхронно и не блокируют первую отрисовку. У hero-изображения выставлен приоритет загрузки для LCP. Для всех изображений заданы `width`/`height`, сдвигов вёрстки при загрузке нет.

## Доступность

Интерактивные элементы — кнопки, а не div или article с ARIA-ролью поверх. У модалок и слайдера расширены кликабельные зоны под сенсорный ввод. Навигация полностью доступна с клавиатуры.

## Запуск

Сборка не требуется — открой `index.html` в браузере.

Для локального сервера:

```bash
npm run dev
```

Поднимет статику на `http://localhost:5173`.

## Стек

HTML5, CSS3, JavaScript (ES6+). Ноль зависимостей в проде.
